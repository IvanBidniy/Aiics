# ASCII Video Bot

**Telegram-бот, який перетворює відео на кольорову ASCII-анімацію.**

Надішли боту ролик, і він поверне MP4, у якому кожен кадр намальований символами `.,:;!+*#%@`. Символ залежить від яскравості ділянки кадру, а його колір береться з відео. Якщо в оригіналі є звук, він зберігається.

## Можливості

| | Параметр |
| --- | --- |
| Вхід | Відео або відеофайл в особистому чаті з ботом |
| Результат | MP4 (H.264), 900 × 600, 24 кадри/с |
| Розмір вхідного відео | До 20 МБ |
| Тривалість | До 2 хвилин |

## Запуск на ПК

Потрібні **Python 3.10+** і **FFmpeg** з підтримкою `libx264`. Переконайся, що команда `ffmpeg -version` працює в терміналі.

1. Створи бота командою `/newbot` у [@BotFather](https://t.me/BotFather) та скопіюй токен.
2. Відкрий термінал у папці з файлом [ascii_bot.py](ascii_bot.py) і виконай:

   ```bash
   python -m pip install "python-telegram-bot>=22,<23" "Pillow>=10.1" numpy
   python ascii_bot.py
   ```

   На Windows, якщо команда `python` недоступна, використовуй `py`. На Linux і macOS може знадобитися `python3`.

3. Встав токен у термінал, коли скрипт його попросить. Також можна передати токен через змінну середовища `TELEGRAM_BOT_TOKEN`. Тримай токен поза репозиторієм.
4. Відкрий бота в Telegram, натисни **Start** і надішли відео. Бот приймає повідомлення, поки запущений скрипт.

## Як працює конвертація

FFmpeg зменшує кадр до сітки **90 × 40** зі збереженням пропорцій. NumPy визначає яскравість і колір кожної клітинки, а Pillow готує маски символів. FFmpeg кодує зібрані кадри у MP4 та додає звукову доріжку з оригіналу, якщо вона є.
